CSS Selectors

Basic CSS Selectors

Name Description Example
Element All HTML elements of the specified type. h2
ID The element on the page with the specified ID. On a given HTML page, each id value should be unique. #my-id
Class The elements on the page with the specified class. Multiple instances of the same class can appear on a page. .my-class
Attribute The elements on the page with the specified attribute. img [src]
Pseudo-class The specified elements, but only when in the specified state. (For example, when a cursor hovers over a link.). a:hover
