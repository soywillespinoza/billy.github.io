Web Dev Cheat Sheet

HTML Tags

Basic HTML Tags

Tag Name Description
<head> Head Includes the document metadata such document title and link to stylesheets.
<title> Title Shows the document title which will be displayed in the browser's title bar/title tab.
<body> Body Only content between the opening and closing body tags can be displayed by the browser.
<h1> Headings There are 6 heading levels (<h1> </h1> to <h6> </h6>) available to give structure and relevance to the text as titles, subtitles and so on.
<div> Division Helps to divide the content in sections to segment HTML elements and apply customized styles for each one (could be images, links or videos).
<p> Paragraph To contain a block of plain text as a paragraph.
<span> Span To contain short pieces of text in the same line as other.
<br> Line Break Insert a line break in the content displayed. This tag doesn't need to close.
<ul> Unordered List Creates a list of items with no particular order.
<ol> Ordered List This ones have the same logic but instead of pointing out with bullets, they do with numbers so you can number items from first to last.
<li> List Item Individual items shouldn't be raw text.
<img> Image Allows to add an image to a web page. It's a self closing tag.
<video> Video insert videos in HTML. Raw text between the tags will show if the the browser is not able to load the video.
<a> Anchor Can add a hyperlink.
<!-- comment --> Comment The syntax to write comments in HTML.
